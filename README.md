# Framework Computer - Embedded Controller Firmware

This is the firmware repository of the Embedded Controller (EC) firmware of Framework Computer systems.
It is a downstream fork of the Chrome EC firmware used by Chromebooks: https://chromium.googlesource.com/chromiumos/platform/ec/
